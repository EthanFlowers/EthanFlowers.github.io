# EthanFlowers.github.io

Source for my personal portfolio site: security write-ups and notes from CTFs, focused on binary exploitation, reverse engineering, and cybersecurity. Built with [Jekyll](https://jekyllrb.com/).

## Deployment

The site is published with GitHub Pages, which builds it directly from the `main` branch. Pushing to `main` triggers a new build and deploy automatically.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000 in your browser.
